# Anvesha

## Overview

Anvesha is visualisation of STEM diagrams so it helps learners understand concept well!

Intial goal of Anvesha is to make NCERT-based materials available at one place where the crucial diagrams of STEM are visualised.

---

## Current Modules

### Science Module
 
- Cell organelles 
    1. Animal cell
    2. Nucleus 
    3. Mitochondria 
    4. Endoplasmic Reticulum
    5. Golgi Apparatus 
    6. Lysosomes
    7. Plant cells
    8. Vacuoles

- Periodic Table 
    1. 2D Cards for each elements 
    2. Bohr simulation [WIP!]

### Math Module

- Pythagoras Simulation
    1. Diagram of how actually Pythagoras theorem can be visualised.
    2. Interactive so you can experiment with different measurements at a scale.
    

- Mensuration Simulation
    Currently available for 2D shapes:
    1. Square 
    2. Rectangle 
    3. Triangle
    4. Trapezium 

    3D shapes [WIP!]

## How to run?

Deployment available on: [Anvesha](https://anvesha-stem.vercel.app/)

But to run locally , ensure you have Node.js installed on your system!

1. Clone the repository:
   ```bash
   git clone [https://github.com/sCherry1101/anvesha.git](https://github.com/sCherry1101/anvesha.git)
   ```

2. Install dependencies 
    ```bash
    npm install
    ```
3. Run
    ```bash
    npm run dev
    ```
